# koishi-plugin-daily-points

签到积分 + 银行 + 模拟股票 + 贷款 + 娱乐 插件（本地版，无需发布市场）。

## 指令分组（二级菜单）

所有指令都挂在「经济」分组下，`help` 不会一屏刷满：

```
经济
├─ 积分：签到 / 查询 / 排行 / 转移 / 修改
├─ 银行：存款 / 取款 / 定期存款 / 定期列表 / 定期取出（入口 = 银行，资产总览）
├─ 贷款：正常贷款（入口） / 高利贷 / 还款 / 欠款 / 打工 / 破产
├─ 股票：行情（入口） / K线 / 买入 / 卖出 / 持仓
└─ 娱乐：赌场 / 猜大小 / 轮盘 / 21点 / 赌场战绩 / 彩票 / 刮刮乐 / 抢劫
```

- 发送 `经济` —— 显示全部指令的总菜单
- 发送 `娱乐` —— 查看娱乐指令概览（含当前赌场奖池、彩票期号）
- 发送 `help 经济` —— 查看分组下的子指令
- **用法完全不变**：所有指令仍可直接用短名调用（`存款 100`、`高利贷 500`、`彩票`、`抢劫 @某人` 等），短名注册为别名

## 命令一览

### 签到 / 积分

| 命令 | 说明 |
| --- | --- |
| `积分签到` | 每天领一次积分，连续签到奖励递增（别名：领取积分、daily-points） |
| `我的积分` | 查询现金、存款、股票市值、欠款、累计与连续签到（别名：积分余额） |
| `积分排行` | 排行榜（别名：points-rank） |
| `积分转移 @某人 数量` | 转移积分 |
| `积分修改 @某人 数量` | 管理员加减积分（3 级权限） |

### 银行

| 命令 | 说明 |
| --- | --- |
| `存款 数量\|全部` | 存入活期，每小时计息（默认 0.1%/小时，复利） |
| `取款 数量\|全部` | 从活期取出（自动先结算利息） |
| `定期存款 数量 3\|7\|30` | 存定期，日利率更高（默认 1% / 1.5% / 2%），到期一次性付息 |
| `定期列表` | 查看定期单：单号、本金、利息、剩余天数 |
| `定期取出 单号` | 到期取出本息；提前取出只还本金（损失利息） |
| `银行` | 资产总览：现金 + 活期 + 定期 + 股票市值 − 欠款 = 净资产 |

### 贷款（正常贷款 + 高利贷）

| 命令 | 说明 |
| --- | --- |
| `贷款` | 查看正常贷款利率与自己的信用额度 |
| `贷款 数量 [天数]` | 申请正常贷款，期限 3 / 7 / 30 天（默认 7），额度 = 净资产 × 倍数（默认 1 倍，净资产为正时最低 100） |
| `高利贷` | 查看地下钱庄条款 |
| `高利贷 数量` | 找地下钱庄借钱：无需信用、单笔上限默认 5000、未结清总额上限默认 10000，期限默认 24 小时 |
| `还款 数量\|全部` | 用现金还贷，优先偿还已逾期的（别名：还贷） |
| `欠款` | 查看每笔贷款的本金、当前应还、利率与到期时间（别名：我的欠款、我的贷款） |
| `打工` | 打工赚积分（默认 5~15，冷却默认 30 分钟；有逾期欠款时收入会被强制划扣 60% 还债）（别名：搬砖） |
| `破产` | 申请破产：债务一笔勾销，但资产全部没收，进入信用黑名单（别名：申请破产） |

### 股票（模拟盘，行情定时刷新）

| 命令 | 说明 |
| --- | --- |
| `股票` | 查看实时行情与涨跌幅、最新消息、新股倒计时（别名：股票列表、股票行情） |
| `K线 [代码] [根数]` | 生成蜡烛图走势图（红涨绿跌，默认 30 根，10~96 根可选；别名：k线、蜡烛图、走势图） |
| `买入 代码 数量` | 用现金按现价买入（停牌股票禁止交易） |
| `卖出 代码 数量` | 卖出换回现金，显示本次盈亏（停牌股票禁止交易） |
| `持仓` | 我的持仓：现价、市值、成本均价、浮盈、累计分红（别名：我的持仓） |

### 娱乐（赌场 / 彩票 / 刮刮乐 / 抢劫，刺激型玩家专享）

| 命令 | 说明 |
| --- | --- |
| `赌场` | 显示三个子游戏规则 |
| `猜大小 数量 大\|小` | 三枚骰子，4-10 为小、11-17 为大；任意豹子庄家通吃（别名：赌大小、大小、ducai） |
| `轮盘 数量 红\|黑\|单\|双` | 0-36 随机一格，按红黑/单双结算（球落 0 庄家通吃）（别名：roulette） |
| `21点 数量` | 开始交互式牌局；玩家和庄家各有一张明牌、一张暗牌（别名：黑杰克、blackjack） |
| `摸牌` | 在当前21点牌局中继续摸一张；达到或超过21点后自动结算 |
| `加注 数量\|全部` | 为当前21点牌局追加押注，累计不能超过赌场单局上限 |
| `开牌` | 停止摸牌、揭示庄家暗牌并结算（别名：展示牌、停牌、stand） |
| `放弃` | 放弃当前21点牌局，返还一半押注（别名：认输、surrender） |
| `赌场战绩` | 查看猜大小、轮盘、21点的累计胜负、下注额和净收益 |
| `彩票 [注数]` | 每注 10 积分，自动生成 6 位号码；每 24h 开奖一次，全中独得奖池（默认 1 注，别名：lottery、caipiao） |
| `刮刮乐 [张数]` | 即买即开，每张 10 积分；安慰 60% / 小奖 30% / 中奖 9% / 大奖 1%（别名：ggl、scratch） |
| `抢劫 @某人` | 抢对方现金，成功率 50%；成功拿 30%，失败赔 50% 且进牢房（别名：抢、打劫、rob） |

## 娱乐机制

### 赌场

- 单笔押注下限 10、上限 5000（可配），两次下注冷却 20 秒
- **普通胜局**按 1:1 赔付；输掉金额默认按 5% 计入**赌场奖池**。该配置名为 `casinoPoolContributionRate`，它只控制奖池注入，不冒充真实庄家优势
- 猜大小：三枚骰子，4-10 为小、11-17 为大；**任意豹子庄家通吃**（标准三骰大小规则）
- 轮盘：球落 0 视为通吃；其他按红黑/单双赔率结算
- 21 点：开局双方各两张牌（各含一张暗牌）；玩家通过后续消息选择摸牌、加注、开牌或放弃。平局退回本金，玩家天然21点按 3:2 获利，庄家可配置是否在软17点继续摸牌
- 21点牌局会持久化到数据库，机器人重启后仍可继续；同一用户的赌场余额操作通过用户级锁串行执行
- 奖池是**全局共享**的，金额会随玩家长期亏损持续累积（`娱乐` 菜单顶部可见）

### 彩票

- **每注 10 积分**，默认 6 位数字（每位 0-9），单期单人最多 20 注
- 玩家发 `彩票` 后自动随机生成号码并入库，扣费后即时返回
- 每 24 小时开奖一次（每 30 分钟定时器检查到期）：随机出 6 位数字
  - **全中**：玩家独得奖池（含本期所有投注 + 上一期滚存），奖池归零
  - **未中**：本期所有投注 + 滚存全部滚入下一期，奖池越滚越大
- 中奖概率 = 1 / 10^digits（默认 1/100 万）；奖池滚存让"长期看头奖独享巨额奖金"
- 手动强开：玩家买彩票时若到期自动开奖，再返回结果

### 刮刮乐

- 每张 10 积分，单次最多 10 张
- 概率分级（默认）：安慰奖 60%（拿回 5）、小奖 30%（赚 20）、中奖 9%（赚 100）、大奖 1%（赚 1000）
- 即买即开，一次消息返回所有张数的结果与盈亏
- 奖额是「纯利润」概念，净收益 = 总奖金 - 总成本

### 抢劫

- 默认成功率 50%（可配）；每次抢劫必须在 30 分钟冷却之后才能再次尝试
- **成功**：从对方现金拿走 30%（按比例），对方现金即时扣减
- **失败**：从自己现金扣 50%（按比例），其中 30% 给被抢的人做"安慰金"，70% 入赌场奖池；然后**进牢房 60 分钟**，期间不能再抢
- **对方现金 < 50** 时不可抢（最低保护线，保护小号玩家）
- 每日上限 5 次（成功+失败合计），超限次日 0 点重置
- 坐牢记录存 `daily_jail`，到时自动清除；冷却检查按 `daily_robbery_log` 最近一条时间戳

## 贷款机制（模拟现实）

- **正常贷款**：按日利率计息（默认 3 天期 3% / 7 天期 2.5% / 30 天期 2%），额度按**净资产**（总资产 − 全部欠款）计算——借款时现金和欠款同时增加，净资产不变，因此**不能借新还旧无限套贷**
- **高利贷**：日利率默认 10%，期限默认 24 小时，无需信用审核，单笔上限默认 5000，未结清总额上限默认 10000；有逾期高利贷时钱庄拒绝再借
- **逾期惩罚**：正常贷款逾期后利率 ×2，高利贷逾期后利率 ×3（倍数可配），利息按小时复利滚动；有逾期贷款时银行冻结信用，不批新贷
- **催收系统**：催收员每小时巡逻一次，对逾期用户按顺序没收资产：现金 → 活期 → 定期本金 → 股票（按市价强制平仓），没收所得自动抵扣欠款（逾期优先）
- **防跑路机制**：有未结清欠款时不能转移积分（防止借钱转给小号后破产逃债）

## 还不起钱怎么办

1. **打工还债**：发送 `打工`（别名 `搬砖`）赚积分，默认 5~15，冷却 30 分钟。有逾期欠款时，收入的 60%（可配）会被催收员当场划扣还债——相当于"工资扣押"
2. **申请破产**：贷款**逾期后**可发送 `破产`，法院裁定通过后：
   - 所有贷款一笔勾销，催收停止
   - 全部资产（现金 / 活期 / 定期 / 股票）没收充公，归零重新开始
   - 进入信用黑名单（默认 7 天）：不能贷款、不能借高利贷、签到收益减半
   - 破产记录永久累计
   - 贷款未逾期时申请会被法院驳回（"你还还得起"）
- 还款支持部分偿还，多付的部分自动退回现金
- 所有贷款数据持久化在 SQLite，重启不丢

## 股票机制

- 初始 6 只股票：大摸鱼控股(DMHJ)、咖啡因生物(KFXW)、熬夜科技(YYKJ)、摸鱼银行(MYYH)、小熊新能源(XHNY)、干饭人食品(GFSP)
- 每 60 分钟（可配置）刷新一次行情：随机游走 + 向基准价均值回归，防止无限暴涨/暴跌
- **K线历史**：每根K线记录开高低收，14 天后自动清理；首次运行自动回填 48 根历史，保证图表不为空
- **K线图**：`K线 代码` 用 puppeteer 渲染蜡烛图（红涨绿跌）发到群里；未启用 puppeteer 时降级为文字走势
- **随机事件**（默认每周期每只 8% 概率）：财报暴雷暴跌、被巨头收购暴涨、涉嫌造假停牌 2~5 个周期、高管跑路、拿下大单——事件消息显示在 `股票` 行情里
- **停牌**：停牌期间价格冻结、禁止买卖，K线走一字，复牌自动恢复
- **新股 IPO**：每 24 个周期（默认 = 每天一只）从候选池随机上市一只新股（神仙快乐水、天马芯片、万物量子等 12 只候选），股票池上限默认 12 只，行情里显示上市倒计时
- **分红**：每周期默认 15% 概率随机一只股票分红，持股者每股得 现价 × 1%（默认），自动存入现金并累计到「持仓」的累计分红里
- 机器人关机期间错过的行情会在下次启动时自动补算（最多 48 个周期，事件/K线同步补算）
- 行情、K线、持仓、存款全部存数据库，重启不丢数据

## 数据表

- `daily_points`：现金(points)、活期(bank)、签到数据、打工时间、破产记录，`userId` = `平台:QQ号`
- `daily_fixed`：定期存款单
- `daily_loans`：贷款单（type: normal / shark，status: active / cleared / bankrupt）
- `daily_stocks`：股票行情（含停牌时间 haltedUntil、事件备注 note）
- `daily_stock_history`：K线历史（每周期一根：开高低收，保留 14 天）
- `daily_stock_holding`：用户持仓（userId+code 唯一）
- `daily_meta`：股票行情刷新水位、IPO 计数、最新消息
- `daily_casino_pool`：赌场全局奖池（单行 id=1）
- `daily_blackjack_sessions`：进行中的21点牌局（押注、牌堆、双方手牌），用于跨重启继续
- `daily_casino_stats`：按用户和游戏累计的赌场胜负、下注额与净收益
- `daily_lottery_periods`：彩票期数（period, status: open/drawn, winningNumber, carriedOver）
- `daily_lottery_tickets`：彩票投注（period, userId, number）
- `daily_scratch_log`：刮刮乐记录（userId, tier, prize）
- `daily_robbery_log`：抢劫记录（robberId, victimId, success, amount），用于冷却和每日上限
- `daily_jail`：坐牢状态（userId, releaseAt, reason），过期自动清

## 配置

所有参数（签到数值、利率、定期利率、贷款利率、高利贷条款、催收间隔、打工收益与划扣比例、破产黑名单天数、行情间隔、波动倍率、股票池上限、IPO 周期、事件概率、分红概率与比例、赌场抽水/限红/冷却、彩票每注价/位数/开奖间隔、刮刮乐奖项概率与奖额、抢劫成功率/比例/冷却/坐牢/日上限）均可在 Koishi 控制台 → 插件配置 → daily-points 中修改。
